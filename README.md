# Froshi's Games

A collection of original browser games.

## Games included
1. Silent Speed Pong
2. Capy Snake
3. Froshi's Casino
4. Capy Chaos
5. Neon Duck Hunt

## How to publish (GitHub Pages)

1. Create a free GitHub account at https://github.com
2. Create a new **public** repository named `froshis-games` (or any name)
3. Upload the entire contents of this folder to the repository
4. Go to Settings → Pages
5. Under "Source", choose "Deploy from a branch"
6. Select branch `main` and folder `/ (root)`
7. Click Save
8. Wait 1–2 minutes
9. Your site will be live at:
   https://YOUR-USERNAME.github.io/froshis-games/

That's it. The site works on Safari, Chrome, Firefox, and mobile.

## Local testing
Just open `index.html` in any browser.
